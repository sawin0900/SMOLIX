SMOLIX + eGames modules — порядок после аудита и backup
=======================================================

Правило: один модуль за раз, один сервер, проверка, откат.

Приоритет для SMOLIX:
1. Backup/Restore (панель) — backup-remnawave-panel.sh; если CLASS=E → rr меню 7
2. Новые ноды на ЧИСТОМ VPS — eGames «Только нода» или ручной Xray:443+SelfSteal
3. WARP Native — только на выбранной ноде (исходящий)
4. Torrent blocker / фильтры — на нодах
5. Xray Checker → данные в SMOLIX GET /status (после того как checker есть)
6. Клиентский балансировщик / sub rules — если появятся native VPN-клиенты
7. NetBird — только если закрываем публичный :2222
8. Cookie-защита панели — ТОЛЬКО с allowlist /api для SMOLIX; высокий риск

- Установить только панель / панель+нода / Переустановить
- Удалить скрипт (п.13) вслепую
