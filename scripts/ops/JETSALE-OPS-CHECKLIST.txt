jetsale.online — операционный чеклист
=====================================

A. Полный цикл (ручной тест, 10–15 мин)
---------------------------------------
1) Регистрация нового email на https://jetsale.online/auth?mode=register
2) Письмо «Добро пожаловать» пришло (HTML)
3) Вход в кабинет /app — trial ACTIVE ~14 дней
4) Скачать ZIP /install → chrome://extensions → unpacked jetsale-chrome
5) Войти в popup тем же email → режим YouTube / Premium
6) В кабинете есть VPN-ссылка / QR (Remnawave shortUuid)
7) На телефоне: импорт ссылки в клиент (FlClashX / Happ / v2rayNG)
8) (после YooKassa) оплата Premium → письмо «Premium активирован» → статус не trial

B. Бэкапы
---------
Скрипт: scripts/ops/backup-jetsale-api.sh
  install -m 700 /var/www/SMOLIX/scripts/ops/backup-jetsale-api.sh /usr/local/bin/backup-jetsale-api.sh
  /usr/local/bin/backup-jetsale-api.sh
  crontab -e:
    15 3 * * * /usr/local/bin/backup-jetsale-api.sh >> /var/log/jetsale-backup.log 2>&1

C. Смена пароля Postgres (если ещё ChangeMe)
--------------------------------------------
1) Новый пароль придумать и сохранить в менеджере паролей
2) sudo -u postgres psql -c "ALTER USER smolix WITH PASSWORD 'НОВЫЙ_ПАРОЛЬ';"
3) В /var/www/SMOLIX/apps/api/.env обновить DATABASE_URL
4) systemctl restart smolix-api
5) Сразу сделать backup-jetsale-api.sh

C2. Chrome-прокси (расширение) — Proxy Manager
---------------------------------------------
Ошибка в popup «Proxy Manager configuration is missing» = на VPS пустые:
  PROXY_MANAGER_URL
  PROXY_MANAGER_TOKEN
  PROXY_CREDENTIALS_KEY   # base64, ровно 32 байта

В /var/www/SMOLIX/apps/api/.env задать (значения — из вашей установки proxy-manager
на ноде rassiya / панели eGames reverse-proxy, НЕ публиковать в git):

  PROXY_MANAGER_URL=https://...   # API менеджера пользователей HTTPS-прокси
  PROXY_MANAGER_TOKEN=...
  PROXY_CREDENTIALS_KEY=...       # openssl rand -base64 32
  PROXY_PUBLIC_HOST=rassiya.jetsale.online
  PROXY_PUBLIC_PORT=8443

Затем:
  systemctl restart smolix-api
  # проверка без секретов:
  grep -E '^PROXY_MANAGER_URL=|^PROXY_MANAGER_TOKEN=|^PROXY_CREDENTIALS_KEY=' /var/www/SMOLIX/apps/api/.env | sed 's/=.*/=***/'

Если URL/TOKEN есть локально в apps/api/.env на дев-машине — скопировать
ТЕ ЖЕ значения на Beget (не генерировать новый CREDENTIALS_KEY, если в БД
уже есть зашифрованные proxyPasswordEncrypted).

D. Cloudflare Turnstile
-----------------------
1) https://dash.cloudflare.com → Turnstile → Add site → jetsale.online
2) Скопировать Site Key + Secret Key
3) В apps/api/.env:
     TURNSTILE_SITE_KEY=...
     TURNSTILE_SECRET_KEY=...
4) В apps/web/.env (или при сборке):
     VITE_TURNSTILE_SITE_KEY=тот_же_site_key
   (API /auth/antibot уже отдаёт site key; VITE нужен если фронт читает из import.meta)
5) npm run build (api+web) && systemctl restart smolix-api
6) На /auth?mode=register должен появиться виджет «я не робот»

D2. SPF / DKIM / DMARC (Beget + DNS jetsale.online)
--------------------------------------------------
Цель: меньше спама, welcome/reset доходят в Inbox.
1) В панели Beget → Почта / DNS для jetsale.online:
   - SPF TXT @ :  v=spf1 include:beget.com ~all
     (если Beget даёт свой include — взять из инструкции почты)
   - DKIM: включить DKIM в Beget для домена, добавить выданный TXT
   - DMARC TXT _dmarc :  v=DMARC1; p=none; rua=mailto:info@jetsale.online; fo=1
2) MAIL_FROM в apps/api/.env = "jetsale.online <info@jetsale.online>" (в кавычках)
3) Проверка: https://mxtoolbox.com/spf.aspx + отправить себе письмо из админки
4) Через 1–2 недели при стабильной доставке: DMARC p=quarantine

D3. Remnawave — больше локаций / стран
-------------------------------------
1) В панели Remnawave добавить ноды (DE/NL/FI/… ) в squad REMWAVE_SQUAD_UUID
2) API /extension/servers уже отдаёт все accessible-nodes с названиями стран
3) Chrome HTTPS-прокси пока на REMWAVE_PROXY_NODE_UUID; телефон/TV — все ноды squad
4) После добавления нод: проверить кабинет QR + список локаций в popup

E. Chrome Web Store
-------------------
1) Developer dashboard → новый item → загрузить ZIP из public/downloads/jetsale-chrome.zip
   (лучше собрать store-пакет без "key" в manifest — Store выдаст свой ID)
2) После публикации:
     VITE_CHROME_STORE_URL=https://chromewebstore.google.com/detail/...
3) Пересобрать web; обновить ALLOWED_EXTENSION_IDS на ID из магазина

F. Оферта / политика
--------------------
Админка → «Оферта / Политика» → заменить плейсхолдеры:
  [НАИМЕНОВАНИЕ / ФИО], [ИНН], [ОГРН/ОГРНИП], [ЮРИДИЧЕСКИЙ АДРЕС], [EMAIL], [ТЕЛЕФОН], [EMAIL ПОДДЕРЖКИ]
EMAIL поддержки: info@jetsale.online

G. Мониторинг
-------------
  journalctl -u smolix-api -n 50 --no-pager
  Админка → Alerts / Remnawave — ноды и open alerts
  curl -s https://jetsale.online/api/health

H. Поддержка
------------
